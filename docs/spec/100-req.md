# REQ

change.create先保存原始文本、交付目标、范围和真实本地授权，分配change/revision/source身份。
phase.submit批量保存需求/验收及来源关系；phase.complete检查覆盖并冻结，创建DSN草稿。
复杂含糊语义由当前Agent澄清；Runtime字段校验不能代替业务判断。
Agent识别冲突后run.request_input记录question/conflict/当前revision及field_path并返回needs_input。
待答事项通过run.get、phase.prepare和status可读；原来源、generation和权限不变。
run.answer_input记录实际回答及其依据，绑定原问题；随后才可继续正式内容或工具操作。
该操作不新增授权、不签human审阅；新Run或取消再重开也不能自动消除未回答的问题。
