# 结构化存储

Python3.11+与SQLite3.37+，32张STRICT表，所有连接启用外键。SQLite是唯一业务Store。
读取事务固定一次快照；写入短事务。请求回执与业务写入同事务；同键同请求回原结果，
同键不同请求冲突。失败业务回滚后独立保存Run/错误回执。草稿CAS拒绝陈旧generation。
附件原字节按SHA256寻址为assets/ab/cd/完整摘要。先完整原子写文件，后提交引用；
提交快照及关联不可修改，孤立文件保留供恢复。阅读页可以重建，原始附件/运行日志不能丢弃。
asset.inspect只读扫描本库assets目录，最多50000项，不跟随符号链接；列出未登记文件、
缺失资产及非法路径。未登记按全库登记表判断，避免把另一项目合法资产误当孤立文件。
该入口不删除数据、不宣称完成内容摘要校验。资产写后事务失败可按原来源与新操作重试登记。

草稿回到上游时以abandoned保留不可改现场，再创建子草稿；不采用、不当作阶段完成。
