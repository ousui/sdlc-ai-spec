# IMP

run.acquire 为工作区取得唯一执行租约。task.next、task.start、task.write、check.run、
task.finish 共用 PLN 的 start/execute/complete 条件。准备完成不代表其环境检查 pass。
执行使用已采用 committed 快照；尚有 draft、过期租约、未回查副作用时返回明确阻断。
task.finish 保存真实文件快照，outcome=not_applicable，不制造测试通过结论。

代码写入通过 task.write 的明确文件批次、资源和计划 scope_paths 进行；支持空文件和删除。
意图、原始/预期文件摘要、内容资产先持久化，实际写入发生在 SQLite 事务外。
未知结果必须 operation.reconcile；回查根据原意图及前后字节处理，外部改动产生冲突。
run.resume 保留中断尝试并轮换租约，旧执行者不能继续写入。

命令使用 argv、明确 cwd、非秘密环境变量白名单、超时和有界脱敏输出。
macOS 收集器由独立单线程启动器应用 Seatbelt 后直接 exec：网络默认拒绝，只允许计划写范围和临时目录；
运行资料、数据库及 Git 元数据不可写。拒绝 setsid、setpgid 和 posix_spawn 系统调用，
正常 fork/exec 可用。Java 自动使用 FORK 进程启动方式；必须使用 posix_spawn 的其他工具需单独适配，不能静默放开。
输出流关闭后仍持续计时，遗留进程组被回收且本次不判 pass。其他系统及不能建立沙箱的宿主明确 blocked。

这不是对任意恶意工具的通用虚拟机隔离；命令仍必须属于用户授权任务。
运行事实包含命令、环境摘要、退出码、日志、输入文件字节与补丁；Collector 回执摘要与业务提交分开落盘，
恢复时不信任单独出现的 result.json，也不重复运行已有有效回执的命令。
