SDLC AI SPEC · MAINTAINER RUNBOOK

上游升级运行流程

sdlc-maintain-upgrade 负责把确定性升级工具编排为一个显式维护流程。默认终点是已验证、未提交的 detached candidate；产品接收、Git 集成和发布属于独立授权操作。

固定边界：维护 Skill 不属于 000–500 业务生命周期，不进入 dist/skills，不修改真实业务项目 .sdlc 数据，也不通过修改 checker、测试、adapter 或忽略规则来使升级通过。

完整升级主链

SKILL1. 显式调用 sdlc-maintain-upgrade TARGET确认目标仓库为 SDLC AI SPEC，读取仓库维护规范并保留用户工作。
↓
SKILL2. 仓库预检记录 source HEAD、分支、产品版本、锁定上游、Python/uv 身份；源工作树必须满足升级工具的清洁要求。
↓
SKILL3. 固定一个准确目标上游latest、tag 或 commit 最终解析成唯一 target ref、exact SHA 和 package version；不隐式跟随 upstream main。
↓
SKILL4. 审查准确 upstream delta检查核心命令、模板/Bash、watch files、宿主集成、初始化、事件、版本和许可证。结构性变化直接进入 REVIEW_REQUIRED。
↓
TOOL5. upgrade.py prepare从已接受源基线创建新的 detached candidate，生成 lock、port 和 dist；当前源分支保持不变。
↓
STATECANDIDATE_READY候选可以进入独立验证。
STATELOCALIZATION_REQUIRED仅在确认错误可由本地化恢复时进入本地化闭环。
STOPBLOCKED / 无 record保留证据，输出 REVIEW_REQUIRED 或环境故障；不修改候选规则求通过。
↓
TOOL6. 创建目标准确上游的三宿主 baseline在新的隔离环境安装 exact target，分别生成 Codex、Claude、Cursor 空项目基线；不以本项目生成物作为 oracle。
↓
TOOL7. 运行候选自身 tools/verify.py验证来源、宿主输出、中文绑定、模板、脚本、Runtime、仓库测试、差分和可复现构建；证据绑定 exact candidate digest 与 target SHA。
↓
RESULTVERIFIED_CANDIDATE_READY输出 candidate 路径、digest、上游差异、本地化变化、完整验证结果和未执行项。默认流程在这里结束。
同版本目标执行同一主链，结果用于 rehearsal；它不改变正式锁定版本。

LOCALIZATION_REQUIRED 恢复闭环

TOOL1. localize.py export从 candidate 导出当前 canonical English inputs 到外部目录。
↓
SKILL2. 增量补译对比旧英文、新英文、旧中文，仅修改 <CANDIDATE>/src/locales/zh-CN/** 中受影响的自然语言内容。
↓
TOOL3. localize.py precheck在写 review record 前只读检查 command、presentation 或 resource 的机器/结构契约。
↓
REVIEW4. 完整语义复核核对义务/禁止、责任主体、条件、数量、布尔和状态、等待/停止、写入目标、命令/路径/标识及兼容输入。
↓
TOOL5. localize.py record → check只记录实际完成审查的变化项，再运行全量本地化检查。reviewer 字段记录真实审查身份。
↓
TOOL6. upgrade.py refresh-localization验证非本地化冻结摘要，重新构建并生成新的 candidate digest。refresh 前的 verifier 证据全部失效。
↓
STATE7. 回到 CANDIDATE_READY重新创建 baseline 并对新 digest 执行完整 verifier。
出现新结构别名、机器契约变化、adapter/code 变化或非本地化冻结内容变化时，本地化恢复立即停止。此类变化属于独立维护修改，并从新的已接受源基线重新 prepare。

状态语义

状态含义允许继续
CANDIDATE_READY候选已生成并拥有确定 candidate digest；不代表 verifier 已通过。创建独立 baseline，运行完整 verifier。
LOCALIZATION_REQUIREDprepare 因本地化检查阻止候选就绪。只有实际错误确认属于受控本地化恢复范围时。
BLOCKED候选无法在当前受支持契约下继续。停止自动升级，保留证据并进入独立维护审查。
VERIFIED_CANDIDATE_READY维护 Skill 的结果状态：exact candidate 已完成独立工程验证。默认停止；后续接收需要独立授权。
REVIEW_REQUIRED结构、机器契约、权限、映射或语义需要维护者决策。不能在当前升级运行中通过修改 checker/tests 绕过。

授权分界

DEFAULT候选验证完成保留 detached candidate、外部证据和最终差异报告；源分支不变。
SEPARATE AUTHORIZATION候选接收 / Git 集成upgrade.py accept、候选提交、接收进升级分支、维护文档收尾和最终字节验证。
SEPARATE AUTHORIZATION合并 / 发布 / 客户端验收main 合并、tag、Release、客户端重新加载与真实项目验收分别记录，互不替代。
