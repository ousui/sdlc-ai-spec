# 身份、覆盖与状态

project_id 隔离逻辑项目，workspace_id/instance_id 标识当前执行现场。change_id 跨阶段保持；
执行入口必须明确需求身份，不能按最新记录猜测。条目UUID由Runtime分配，同批使用client_key。
来源/覆盖、执行前驱、操作前置及资源冲突分别表达。REQ需求有来源及验收，DSN覆盖需求并定义方法，
PLN覆盖设计和验收。共享覆盖校验不会把来源作为执行依赖。
内容草稿使用generation；完成后提交不可变快照，下阶段复制子快照并保留条目身份。
阶段完成、检查pass、AI审阅和真实授权分别记录，auto不产生人工签名或独立审查身份。
