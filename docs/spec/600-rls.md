# RLS 本地交付

需求创建时固定delivery_mode与delivery_target。首版local支持
`.sdlc/exports/<name>/<package_sha256>.zip`；git/deployment返回adapter unavailable。

PLN须有一个required、purpose=release_readback、executor=command的Check，
argv=`["@runtime","delivery.readback"]`；input_paths省略时使用完整main，显式只读范围确定交付源码集合。
同root多产品应在DSN/PLN固定各自源码范围，包及后续输入适用性均使用该准确范围；
不在delivery.prepare临时缩小，不能自动把兄弟项目代码加入本需求交付。
VFY收敛后，当前Agent启动RLS任务，调用delivery.prepare、delivery.execute，完成任务后
phase.complete RLS；准备不代表交付完成。

prepare固定代码/环境/验证摘要和包字节。execute写出后用独立worker检查同一份字节的摘要、
条目安全性及完整manifest。包变更、输入失效、回读过期、任务未完成、VFY缺口均阻止关闭。
同一目标可以保留多个内容版本，任何现存不同字节文件都不被覆盖。

unknown先operation.reconcile；重复回读不重新发布丢失文件；历史PASS不能代替当前目标回读。
关闭后使用不带已关闭run_id的新workspace.export请求，payload.change_id选择本需求，
归档完整结构化事实、原始证据和离线阅读入口。RLS过程不自动提交Git、发布或部署。
