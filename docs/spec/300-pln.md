# PLN

任务保存target_phase、kind、scope_paths、completion_text及设计/验收关系。
add_task_dependency是执行前驱，precondition引用实际Check和责任任务及生效时点。
共享图包含start→execute→complete；检查于责任任务execute产生，完成时自检允许，
开始或执行等待自身未来检查拒绝。混合环及逆阶段关系在PLN提交端拒绝。
完成PLN保留不可变快照并指向IMP；任务完成不能代替环境检查pass。

Check 可单独声明 input_paths 读依赖闭包；默认完整main产品输入，不能从任务写范围推导。
