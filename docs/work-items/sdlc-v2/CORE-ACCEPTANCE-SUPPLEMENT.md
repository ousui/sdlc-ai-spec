# Q0 后内核验收补充

基于批准设计46项的独立复核，补齐首版本地核心行为。没有新增 Schema 表、外部服务或授权类型。

## 行为和决定

- V2-005：公开 `run.request_input` / `run.answer_input` 承接 Agent 识别的需求冲突。
  问题、字段位置、原版本和恢复入口持久化；待回答时阻止继续写正式内容或执行副作用。
  取消或新建 Run 不能抹掉同一需求的问题。回答保存当前 Agent 身份及依据，不授予权限。
- V2-028：只读 `asset.inspect` 报告孤立文件、缺失引用和非法路径；有界扫描，不跟随符号链接，
  不删除资产，不声称完整性校验。真实进程在文件写入后、数据库提交前退出，重试可正确关联一次。
- V2-031：独立 SIGKILL 反例发现已收到完整行仍会丢失。收集器现在及时保存脱敏完整行；
  未结束的最后一行仍可能丢失。中断日志不能形成 PASS，未知副作用须回查，活进程禁止重放。
  未闭合私钥块也脱敏。澄清字段路径的原始秘密泄漏反例同时修复，响应和持久阅读视图均验证。
- V2-044：同库两项目真实交付发现原生回读强制整个 main，导致兄弟项目代码混入。
  现在使用 DSN/PLN 已提交 Check 的 input_paths 决定代码集；省略时仍为完整 main。
  交付时不能临时缩窄；无关项目编辑不使已准备包失效，本项目编辑必须拒绝旧包。
- V2-007/013/039：补默认五轮真实失败停止、九项验收完整进入 PLN、shell 特殊字符按字面执行的回归。
  离线归档测试移走原工作目录后，验证数据、原始请求与全部首页链接仍可读。
